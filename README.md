# 🤖 دستیار هوش مصنوعی — سایت چت + ربات تلگرام

یک سرور Node.js/Express که هم **سایت چت** دارد و هم به‌عنوان **وبهوک ربات تلگرام** کار می‌کند.
پاسخ‌ها از [CodeCraft API](https://codecraftapi.com) (مدل `gpt-5.6-luna`) می‌آید.

همه‌چیز فقط با مرورگر و اپ تلگرام انجام می‌شود — نیازی به نصب Node یا ترمینال روی کامپیوترت نیست.

## ✨ امکانات

- **سایت چت** با تم روشن و تیره، نمایش مارکداون (کد، لیست، جدول)، کپی پاسخ و ذخیره‌ی تاریخچه در مرورگر
- **ربات تلگرام** با حافظه‌ی مکالمه، نشانگر «در حال تایپ» و قالب‌بندی درست پاسخ‌ها
- **سیستم توکن دسترسی** برای کنترل اینکه چه کسی می‌تواند با ربات صحبت کند
- **پنل ادمین** داخل تلگرام: ساخت و مدیریت توکن‌ها و ارسال اعلامیه برای همه‌ی کاربران
- **محدودیت تعداد پیام** روی سایت برای جلوگیری از مصرف بی‌رویه‌ی اعتبار API

---

## مرحله ۱ — ساخت ربات تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` را بفرست.
3. یک اسم و یک یوزرنیم (باید به `bot` ختم شود، مثلاً `MyAiHelper_bot`) انتخاب کن.
4. BotFather یک **توکن** می‌دهد، شبیه: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   آن را جایی امن نگه دار.

---

## مرحله ۲ — آپلود پروژه در گیت‌هاب

1. وارد [github.com](https://github.com) شو و یک ریپوی جدید بساز (پیشنهاد: **Private**).
2. **Add file → Upload files** را بزن و همه‌ی فایل‌های پروژه را بکش و رها کن.
3. **Commit changes** را بزن.

> فایل `.gitignore` جلوی آپلود `node_modules`، `.env`، `data.json` و `about-me.txt` را می‌گیرد.
> اگر با مرورگر آپلود می‌کنی، خودت این فایل‌ها را انتخاب نکن.

> ⚠️ **نکته‌ی امنیتی:** کلید API و توکن ربات را هیچ‌وقت داخل فایل‌های پروژه ننویس.
> آن‌ها فقط باید در پنل هاست (مرحله‌ی بعد) وارد شوند.

---

## مرحله ۳ — هاست رایگان (Render.com)

1. وارد [render.com](https://render.com) شو و با حساب گیت‌هابت ثبت‌نام کن.
2. **New → Web Service** را بزن و ریپوی مرحله‌ی ۲ را انتخاب کن.
3. تنظیمات:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
4. در بخش **Environment Variables** مقدارهای جدول زیر را اضافه کن.
5. **Create Web Service** را بزن و صبر کن تا دیپلوی تمام شود.
6. آدرس سرویس را کپی کن، مثل `https://ai-telegram-bot-xxxx.onrender.com`

### متغیرهای محیطی

| نام | ضروری | توضیح |
|---|:---:|---|
| `CODECRAFT_API_KEY` | ✅ | کلید CodeCraft API (شبیه `cc_xxxxxxxx`) |
| `TELEGRAM_BOT_TOKEN` | ✅ | توکن ربات از BotFather |
| `ADMIN_TELEGRAM_ID` | | آیدی عددی تلگرام خودت (برای دسترسی ادمین) |
| `ADMIN_PASSWORD` | | رمز ورود به پنل ادمین (`/admin`) |
| `ABOUT_ME_TEXT` | | متن معرفی صاحب ربات؛ اگر خالی باشد از فایل `about-me.txt` خوانده می‌شود |
| `CODECRAFT_MODEL` | | نام مدل. پیش‌فرض: `gpt-5.6-luna` |

> پلن رایگان Render بعد از ۱۵ دقیقه بی‌کاری می‌خوابد و اولین پیام بعدی ممکن است ۳۰ تا ۶۰ ثانیه طول بکشد.
> با [UptimeRobot](https://uptimerobot.com) می‌توانی هر چند دقیقه آدرس `/health` را پینگ کنی تا سرویس بیدار بماند.
>
> همچنین دیسک Render در پلن رایگان موقتی است؛ با هر دیپلوی جدید، فایل `data.json` (توکن‌ها و لیست کاربران) پاک می‌شود.

---

## مرحله ۴ — وصل کردن وبهوک تلگرام

آدرس زیر را با اطلاعات خودت پر کن و در مرورگر باز کن:

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://ai-telegram-bot-xxxx.onrender.com/telegram-webhook
```

اگر پیام `{"ok":true,"result":true,...}` را دیدی، وصل شده است ✅

---

## مرحله ۵ — تست

- **سایت:** آدرس Render را در مرورگر باز کن.
- **تلگرام:** به رباتت برو، `/start` را بزن و هر سوالی بپرس.

---

## اجرای لوکال (اختیاری)

```bash
npm install
cp .env.example .env   # و مقدارها را پر کن
npm run dev
```
